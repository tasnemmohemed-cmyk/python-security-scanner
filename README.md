# Python Code Security Scanner

Status: Under Active Development (Phase 1)

A simple desktop application built with Python and Flet to scan Python code or project folders for potential vulnerabilities, calculate a safety percentage, and generate security reports.

## Features
- Desktop GUI built with Flet.
- Scan code directly or select a project folder.
- Detects potential security flaws and calculates a safety percentage.
- Generates automated security reports.

## Future Plans
- Phase 2: Add attack simulation features on tested code.
- Phase 3: Support more languages like C++ and Java.

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the app:
   python sec.py
